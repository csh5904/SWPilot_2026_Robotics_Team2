오일러 경로(Euler Path) 탐색

그래프 자료구조 · 오일러 서킷 · Hierholzer 알고리즘 기반 구현

1. 오일러 서킷(Euler Circuit)의 개념

오일러 경로(Euler Path)는 그래프의 한 정점에서 출발하여, 그래프에 존재하는 모든 간선을 정확히 한 번씩만 지나서 도착하는 경로를 말한다. 이때 출발점과 도착점이 같으면 오일러 서킷(Euler Circuit) 또는 오일러 회로라고 부른다.

이 개념은 1736년 레온하르트 오일러(Leonhard Euler)가 “쾨니히스베르크의 다리 문제”를 풀면서 처음 제시되었다. 도시를 가로지르는 7개의 다리를 한 번씩만 건너서 원래 위치로 돌아올 수 있는가 하는 문제였는데, 오일러는 이를 그래프(정점과 간선)로 추상화하여 각 정점(땅 덩어리)에 연결된 간선(다리)의 개수, 즉 차수(degree)를 기준으로 답할 수 있음을 증명했다.

오일러 경로/서킷의 존재 조건

무방향 그래프에서 다음 두 조건으로 판별한다.

  1. 연결성: 간선을 가진 모든 정점은 하나의 연결 요소로 이어져 있어야 한다. (고립된 정점은 무시)
  2. 차수 조건
    홀수 차수 정점 개수결과
    0개오일러 서킷 존재 (임의의 정점에서 출발 가능)
    정확히 2개오일러 경로 존재 (두 홀수 차수 정점 중 하나에서 출발 → 다른 하나에서 종료)
    3개 이상오일러 경로/서킷 모두 존재하지 않음
이번 과제의 그래프는 “홀수 차수 정점이 두 개”인 경우, 즉 반오일러 그래프(semi-Eulerian graph)에 해당한다.

2. 그래프 자료구조

그래프(Graph)는 정점(Vertex, Node)의 집합과 정점들을 연결하는 간선(Edge)의 집합으로 이루어진 자료구조로, 객체 간의 관계나 연결 상태를 표현하는 데 사용된다.

주요 표현 방식

  • 인접 행렬(Adjacency Matrix): V x V 크기의 2차원 배열로, 간선 존재 여부를 O(1)에 확인할 수 있지만 희소 그래프에서는 공간 낭비가 크다.
  • 인접 리스트(Adjacency List): 각 정점마다 연결된 정점들의 목록을 저장한다. 공간 효율이 좋아 DFS/BFS 등 그래프 탐색에 널리 쓰인다.

이번 과제의 graph 변수는 딕셔너리 기반 인접 리스트로 구현되어 있다.

graph = {
    1: [2, 3],
    2: [1, 3, 4],
    3: [1, 2, 5],
    4: [2, 5],
    5: [3, 4]
}

각 정점의 차수(리스트 길이)를 세어 보면 1→2, 2→3, 3→3, 4→2, 5→2로, 차수가 홀수인 정점은 2와 3뿐이다. 따라서 이 그래프는 정점 2와 3 중 하나에서 출발해 다른 하나에서 끝나는 오일러 경로를 가진다.

3. 알고리즘 학습: DFS 기반 간선 제거 방식

모든 간선을 한 번씩 방문하는 대표적인 알고리즘으로 Hierholzer 알고리즘이 있다. 기본 아이디어는 다음과 같다.

  1. 시작 정점에서 더 이상 갈 수 있는 간선이 없을 때까지 인접한 간선을 따라가며, 지나간 간선은 그래프에서 제거한다(양방향이므로 양쪽 인접 리스트에서 모두 제거).
  2. 간선을 따라 이동하는 과정에서 아직 방문하지 않은 정점을 만나면 그 정점으로 재귀적으로 들어간다.
  3. 더 이상 나갈 간선이 없는 정점에 도달하면 재귀를 빠져나오며, 원래 정점으로 돌아와 남은 간선이 있으면 다시 탐색을 이어간다.
  4. 모든 간선이 소진될 때까지 이 과정을 반복한다.

정식 Hierholzer 알고리즘은 막다른 지점에서 되돌아 나올 때 방문 순서를 스택에 쌓았다가 마지막에 뒤집어(post-order) 완전한 오일러 회로/경로를 구성한다. 이번 과제에서는 그래프가 비교적 단순하고, “경로 상에서 만나는 꼭짓점”만 순서대로 반환하면 되므로, 정점을 처음 만나는 시점에 바로 기록하는 방식(pre-order)으로도 목적을 달성할 수 있다.

간선을 하나씩 제거하며 진행하므로 같은 간선을 두 번 지나가지 않는다. 이미 방문한 정점으로 되돌아가는 간선은 소비(제거)만 되고 목록에는 중복 기록되지 않는다. 모든 간선이 제거되어야 탐색이 끝나므로, 오일러 경로 조건을 만족하는 그래프라면 함수 종료 시 모든 간선이 정확히 한 번씩 소비된 상태가 된다.

4. 구현

import copy
graph = {
    1: [2, 3],
    2: [1, 3, 4],
    3: [1, 2, 5],
    4: [2, 5],
    5: [3, 4]
}
visted=[]
def dfs(graph, start, visited):
    visited.append(start)
    while graph[start]:
        neighbor = graph[start][0]
        graph[start].remove(neighbor)
        graph[neighbor].remove(start)
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
    return visited

print(dfs(copy.deepcopy(graph),2,visted))

5. 실행 결과

[2, 1, 3, 5, 4]

주어진 graph(정점 5개, 간선 6개, 홀수 차수 정점 2, 3)에서 정점 2를 출발점으로 삼으면 모든 간선을 한 번씩 소진하며 [2, 1, 3, 5, 4] 순서로 정점을 만난다.
